
## 项目架构概览

这是一个基于 **Flask** + **SQL Server** 的学术文献检索系统，采用经典的 MVC 分层设计：

- **入口层**：`app.py` 负责应用创建、蓝图注册、错误处理、自定义模板过滤器。
- **配置层**：`config.py` 集中管理所有配置项。
- **数据库层**：`db.py` 提供请求级连接管理，`captcha.py` 生成图形验证码，`utils.py` 提供通用工具函数。
- **路由层（Controller）**：`routes/` 目录下的各个蓝图模块，处理不同业务功能。
- **视图层（View）**：`templates/` 目录下的 Jinja2 模板，负责前端页面渲染。
- **静态资源层**：`static/css/` 和 `static/js/` 存放全局样式和交互脚本。

下面逐一说明每个文件的具体作用。

## 根目录文件

|          文件          | 作用                                                                                                                                                                                              |
| :------------------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|      **app.py**      | 应用程序入口文件。包含 `create_app()` 工厂函数，负责：<br>• 加载配置<br>• 创建上传目录<br>• 注册所有蓝图<br>• 注册 `teardown_appcontext` 钩子（自动关闭数据库连接）<br>• 添加自定义 Jinja2 过滤器 `highlight`（用于搜索结果关键词高亮）<br>• 注册全局错误处理器（404, 500, 通用异常） |
|    **config.py**     | 项目配置文件，定义了：<br>• `SECRET_KEY`：Session 加密密钥（优先从环境变量读取）<br>• `UPLOAD_FOLDER`：PDF 文件存放路径<br>• `MAX_CONTENT_LENGTH`：上传文件大小限制（50MB）<br>• `DB_CONNECTION_STRING`：SQL Server 数据库连接串（使用 Windows 身份验证）   |
|      **db.py**       | 数据库连接管理模块。利用 Flask 的 `g` 对象在单个请求内复用同一个数据库连接，请求结束后由 `close_connection` 自动关闭，避免连接泄漏。提供 `get_connection()` 供各路由调用。                                                                                 |
|    **captcha.py**    | 图形验证码生成工具。使用 `PIL` 库生成包含随机数字/字母的图片，并添加干扰线和噪点，防止机器识别。提供 `generate_captcha_response()` 返回图片字节流和验证码文本，供 `/captcha` 路由调用。                                                                           |
|     **utils.py**     | 公共工具函数集合：<br>• `process_keywords()`：处理文献关键词，将关键词插入或复用 `Keywords` 表，并关联到 `DocumentKeyword` 表（用于 TF-IDF 等扩展）<br>• `get_pagination()`：计算分页参数（当前页、偏移量、总页数），供所有列表页复用                                 |
| **requirements.txt** | 项目依赖清单，包含 `Flask`、`pyodbc`、`pdfplumber`、`Pillow` 等核心库，方便一键安装环境。                                                                                                                                 |

## routes/ 路由模块（后端业务逻辑）

所有路由都使用 **Blueprint** 组织，在 `app.py` 中统一注册。

|        文件         | 作用                                                                                                                                                                                                                                                                                                                                     |
| :---------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`__init__.py`** | 标识 `routes/` 为 Python 包，使 `app.py` 能够 `from routes.auth import auth_bp`。                                                                                                                                                                                                                                                               |
|    **auth.py**    | 用户认证模块（蓝图 `auth_bp`）。处理：<br>• `/` 首页（根据登录状态跳转）<br>• `/login` 登录（含失败尝试计数和账户锁定30分钟）<br>• `/register` 注册（含用户名、密码、邮箱、安全问题校验）<br>• `/forgot_password` 找回密码（含验证码、安全问题验证、重置密码）<br>• `/logout` 退出登录<br>• `/captcha` 生成验证码图片（调用 `captcha.py`）                                                                                                   |
|  **document.py**  | 文献操作模块（蓝图 `document_bp`）。处理：<br>• `/document/<int:doc_id>` 文献详情页（含浏览次数统计、浏览历史记录、关键词显示、被引次数）<br>• `/upload` 上传文献（PDF 文件保存、提取全文、关键词处理）<br>• `/download/<int:doc_id>` 下载 PDF 文件（下载次数+1）<br>• `/my_documents` 当前用户上传的所有文献列表<br>• `/delete_document/<int:doc_id>` 删除文献（同时清理引用、收藏、关键词关联，并删除孤立关键词）<br>• `/edit_document/<int:doc_id>` 编辑文献元数据 |
|   **search.py**   | 搜索与历史模块（蓝图 `search_bp`）。处理：<br>• `/search` 文献检索（支持标题、作者、分类、关键词、全文五种检索类型，以及高级筛选和分页）<br>• `/history` 显示检索历史和浏览历史（折叠面板、分页）<br>• `/clear_history` 清空检索历史<br>• `/clear_browse_history` 清空浏览历史<br>• 搜索时自动记录关键词到 `SearchHistory`，并更新 `UserSearchCount` 和 `KeywordSearchCount` 用于统计                                                            |
| **favorites.py**  | 收藏功能模块（蓝图 `favorites_bp`）。处理：<br>• `/favorites` 显示当前用户的收藏列表（分页）<br>• `/toggle_favorite` 收藏/取消收藏（AJAX 接口，返回 JSON）                                                                                                                                                                                                                       |
|  **citation.py**  | 引用关系管理模块（蓝图 `citation_bp`）。处理：<br>• `/citation/<int:doc_id>` 引用设置页面（仅允许文献上传者操作）<br>• `/search_citation` 搜索可引用的文献（AJAX 接口，返回 JSON）<br>• `/save_citation/<int:doc_id>` 保存引用关系（批量插入/删除）                                                                                                                                                   |
|  **profile.py**   | 个人信息管理模块（蓝图 `profile_bp`）。处理：<br>• `/profile` 展示并修改个人信息（包括修改邮箱、修改密码、修改安全问题，均需验证当前密码）                                                                                                                                                                                                                                                   |
|   **stats.py**    | 数据统计模块（蓝图 `stats_bp`）。处理：<br>• `/stats` 展示系统统计信息：热门关键词排行、活跃用户排行、高被引文献排行、热门浏览/下载/收藏文献排行（各 TOP 10）                                                                                                                                                                                                                                       |

## static/ 静态资源

### CSS 样式

|        文件        | 作用                                                                                                                                                                                |
| :--------------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **css/main.css** | 全局样式文件，集中管理所有自定义样式。包括：<br>• 按钮悬停动效（`.btn-hover`）<br>• 搜索结果高亮（`.search-highlight`）<br>• 历史记录悬停动画（`.history-item`）<br>• 个人信息卡片悬浮（`.form-card`）<br>• 首页渐变背景和浮动元素动画<br>• 上传表单项滚动出现动画等 |

### JavaScript 脚本

|         文件          | 作用                                                                                |
| :-----------------: | --------------------------------------------------------------------------------- |
|    **js/app.js**    | 全局公共 JS，提供**折叠面板**的展开/收起功能（`panel-header` 点击切换），所有使用折叠面板的页面（如历史、个人信息、搜索筛选）都依赖此脚本。 |
|  **js/captcha.js**  | 验证码交互逻辑：点击验证码图片刷新（`refreshCaptcha`），点击输入框时若为空则自动刷新，用于 `forgot_password.html`。     |
| **js/citation.js**  | 引用设置页交互：在 `citation.html` 中，点击“搜索文献”按钮时，异步请求 `/search_citation` 并渲染结果列表（带复选框）。    |
| **js/document.js**  | 文献详情页交互：提供 `toggleFavorite()` 函数，实现收藏/取消收藏的异步切换（更新按钮样式和文字）。                       |
| **js/favorites.js** | 收藏列表页交互：提供 `cancelFavorite()` 函数，点击“取消收藏”按钮时弹出确认框，异步取消收藏并刷新页面。                    |
|   **js/index.js**   | 首页打字机效果：在 `index.html` 中循环显示多条带图标的功能描述，实现逐字打印和擦除动画。                               |
|  **js/search.js**   | 搜索页预留脚本（当前为空，可扩展页面专属逻辑，如筛选条件联动）。                                                  |
|  **js/upload.js**   | 上传页交互：<br>• 自定义日期选择器（点击文字输入框弹出原生日期选择器并同步值）<br>• 上传按钮防重复点击（提交后禁用按钮并显示“上传中...”）     |

## templates/ 模板文件（前端页面）

所有模板继承自 `base.html`，通过 `{% block %}` 实现内容替换。

|            文件            | 作用                                                                                                                                                                                                                    |
| :----------------------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|      **base.html**       | 基础布局模板，包含：<br>• HTML 骨架（引入 Tailwind CSS、Font Awesome、全局样式和 app.js）<br>• 导航栏（根据 `session.username` 显示不同菜单）<br>• Flash 消息显示区域<br>• 主内容区块（`{% block content %}`）<br>• 页脚（包含作者信息）<br>• 额外脚本区块（`{% block extra_script %}`） |
|      **index.html**      | 首页（未登录时的欢迎页）。包含：<br>• 动态渐变英雄区，带打字机效果（调用 index.js）<br>• 六个核心功能卡片<br>• 三个数据统计数字（1000+文献等）<br>• 登录/注册入口                                                                                                                  |
|      **login.html**      | 登录页面。包含品牌展示区（左栏）和登录表单（右栏），显示错误信息（如密码错误、账户锁定）。                                                                                                                                                                         |
|    **register.html**     | 注册页面。包含品牌展示区（带文献简史时间线）和注册表单（用户名、邮箱、密码、确认密码、两个安全问题）。                                                                                                                                                                   |
| **forgot_password.html** | 忘记密码页面。分两步：<br>• 第一步：输入用户名和图形验证码，获取安全问题<br>• 第二步：回答两个安全问题并设置新密码（含锁定机制）                                                                                                                                                |
|     **search.html**      | 文献检索页面。包含：<br>• 搜索框（关键词 + 检索类型下拉）<br>• 高级筛选折叠面板（标题、作者、分类、关键词、全文、日期范围）<br>• 分类浏览折叠面板（显示所有分类，点击快速筛选）<br>• 搜索结果列表（支持关键词高亮）<br>• 分页导航                                                                                     |
|     **history.html**     | 历史记录页面。包含两个折叠面板：<br>• 检索历史（显示关键词、时间，支持重新搜索和清空）<br>• 浏览历史（显示文献标题、作者、时间，支持查看详情）<br>两个面板各自分页，共用页码参数。                                                                                                                     |
|    **document.html**     | 文献详情页。显示文献元数据（标题、作者、分类、发表日期、浏览/下载次数、关键词、被引次数）、摘要、收藏按钮、下载按钮，以及引用本文的文献列表。                                                                                                                                               |
|  **my_documents.html**   | 我的文献列表。展示当前用户上传的所有文献，每行提供“查看”、“设置引用”、“下载”、“编辑”、“删除”操作按钮。                                                                                                                                                              |
|  **edit_document.html**  | 编辑文献页面。表单包含标题、作者、分类、发表日期、关键词、摘要，提交后更新文献元数据（不包括 PDF 文件）。                                                                                                                                                               |
|    **favorites.html**    | 我的收藏列表。展示用户收藏的文献，每行提供“查看”、“下载”、“取消收藏”按钮，支持分页。                                                                                                                                                                         |
|    **citation.html**     | 引用关系设置页面。包含：<br>• 当前文献标题展示<br>• 搜索关键词输入框和搜索按钮<br>• 搜索结果区域（动态渲染复选框列表）<br>• 保存引用关系按钮<br>• 仅文献上传者可访问                                                                                                                     |
|     **profile.html**     | 个人信息页面。包含三个折叠面板：<br>• 修改邮箱（需验证当前密码）<br>• 修改密码（需验证当前密码）<br>• 修改安全问题（需验证当前密码）<br>并显示用户名（不可改）和脱敏邮箱。                                                                                                                      |
|      **stats.html**      | 数据统计页面。以卡片网格展示：<br>• 热门关键词排行<br>• 活跃用户排行<br>• 高被引文献排行<br>• 热门浏览文献排行<br>• 热门下载文献排行<br>• 热门收藏文献排行                                                                                                                       |
|     **upload.html**      | 上传文献页面。包含表单（PDF 文件、标题、作者、分类、发表日期、关键词、摘要），提交后调用 `/upload` 路由。                                                                                                                                                          |
|      **error.html**      | 错误提示页面。显示自定义错误信息，并提供“返回首页”和“返回上一页”按钮，由全局错误处理器渲染。                                                                                                                                                                      |

## 总结

整个项目文件结构清晰，职责分明：
- **后端**：Flask 蓝图划分业务模块，数据库连接由 `db.py` 统一管理，工具函数集中复用。
- **前端**：采用 Tailwind CSS 快速布局，自定义 CSS 控制动效，独立 JS 文件处理交互，模板继承提高复用性。
- **关键特性**：用户认证（含锁定）、文献上传与全文提取、多维度检索、引用关系管理、收藏功能、浏览/检索历史、数据统计，完全满足毕业设计要求。
